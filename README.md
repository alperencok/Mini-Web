# NovaStore - E-Commerce Web App

A responsive e-commerce product catalog and shopping cart web application built with React, Vite, and Tailwind CSS.

## Features

- **Product Showcase:** Browse products with categories, pricing, stock indicators, and ratings.
- **Search & Filter:** Filter products by category and search by title in real time.
- **Shopping Cart:** Add items, modify quantities, remove items, and view subtotal calculation.
- **Responsive Design:** Mobile-friendly drawer and desktop sidebar layouts.
- **Checkout Modal:** Order confirmation dialog with order ID generation and cart reset.

## Tech Stack

- React 18
- Vite
- Tailwind CSS

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alperencok/Mini-Web.git
   cd Mini-Web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
